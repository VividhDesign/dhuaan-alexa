Dhuaan for Alexa+ — Privacy Policy

Effective date: 23 October 2026

Dhuaan for Alexa+ does not ask for or store personal information. Each request carries only the place you ask about. We log the place text, tool name and response time for 30 days to keep the service working and improve accuracy. We don't use cookies, track location, sell data or share it. Contact: GitHub issues at https://github.com/VividhDesign/dhuaan-alexa/issues.
